MANGROVE - GitHub Pages

1. Extract this ZIP. Upload the extracted files, not the ZIP.
2. Put index.html, app.js, style.css, menu.json, symbols.json and the entire
   assets folder in your repository ROOT.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Wait for GitHub Pages to publish your URL.

The website contains 49 main dishes and 9 side dishes, with 24 food photos.
All food photos have transparent backgrounds and use optimized WebP files.
Original photo dimensions and alpha transparency are preserved.
No installation or build is required. Open through GitHub Pages, not by
double-clicking local index.html, because the menu loads JSON files.

If replacing an earlier package, replace menu.json and the entire assets folder too.
